# Knox Survivors - Tradução PT-BR (Injetor Dinâmico)

> **⚠️ Projeto Temporário:** Esta tradução atua como um injetor dinâmico para fins de testes e feedback da comunidade. O objetivo final é que estes arquivos sejam integrados de forma nativa pelo autor do mod original.

---

## 📥 Como Instalar

1. Baixe o arquivo `KnoxSurvivors_PTBR.zip` na aba **Releases** deste repositório.
2. Extraia o arquivo compactado. Você encontrará os seguintes ficheiros principais:
   * `KS_PTBR_Injetor.lua`
   * `sandbox.json`
3. Copie e cole esses arquivos nos caminhos exatos dentro da pasta do mod original **KnoxSurvivors**:

   * **Onde colocar o `KS_PTBR_Injetor.lua`:**
     ```text
     .../Steam/steamapps/workshop/content/108600/3749727604/mods/KnoxSurvivors/media/lua/client/
     ```
   * **Onde colocar o `sandbox.json`:**
     ```text
     .../Steam/steamapps/workshop/content/108600/3749727604/mods/KnoxSurvivors/media/lua/shared
     ```
     

---

## 🔄 Como Desinstalar
Basta apagar os dois arquivos (`KS_PTBR_Injetor.lua` e `sandbox.json`) das respetivas pastas. Como é um injetor dinâmico, os arquivos originais do mod principal não sofrem alterações permanentes.
